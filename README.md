# 🎓 AI 리터러시 & 맞춤형 프롬프트 튜터 (AI Pedagogy Interactive Tutor)
> **AI교수법기초 과제 제출용 단일 페이지 인터랙티브 웹 애플리케이션 (SPA)**  
> 비고츠키(Vygotsky)의 ZPD 비계설정과 RCTF 프롬프트 프레임워크를 융합한 반응형 웹 튜터

---

## 📌 1. 프로젝트 개요 (Overview)

본 애플리케이션은 **‘AI교수법기초’** 교과목의 과제 제출을 목적으로 기획·개발된 단일 페이지 웹 애플리케이션(SPA)입니다.

단순히 AI 도구의 사용법을 소개하는 데 그치지 않고, **교육공학의 핵심 이론(비고츠키의 근접발달영역(ZPD), 파이비오의 이중 부호화 이론)**을 인터페이스와 상호작용 프로세스 전반에 직접 녹여냈습니다. 예비 교원과 학습자가 **AI의 효율성(도구)**과 **교수자의 고유 가치(정서적 교감, 환각 검증, 윤리성)**를 체득하고, 수업 현장에 최적화된 **RCTF 표준 교육 프롬프트**를 실시간으로 설계할 수 있도록 돕습니다.

## 🏛️ 2. 교육공학적 이론 토대 및 설계 원리

본 프로젝트는 다음의 4가지 교수학적 핵심 기둥을 바탕으로 설계되었습니다:

### ① AI의 역할(효율성) vs 교수자의 고유 영역(인간적 가치)
* **AI의 역할**: 대량의 초안 생성(수업지도안, 연습문제), 24시간 개별 맞춤형 연습 피드백, 반복 업무 경감
* **교수자의 고유 영역**: 학습자의 좌절과 동기를 읽어내는 **정서적 교감(Rapport)**, AI의 생성 오류를 가려내는 **환각(Hallucination) 검증 및 비판적 사고 지도**, 전인적 인성과 **디지털 윤리성 함양**

### ② 비고츠키(Vygotsky)의 근접발달영역(ZPD) & 비계설정(Scaffolding)
* 학습자가 스스로 해결할 수 있는 **'실제적 발달 수준'**과 유능한 타자(교사, 동료, 또는 AI)의 도움으로 도달할 수 있는 **'잠재적 발달 수준'** 사이의 간극(ZPD)에 주목합니다.
* AI가 정답을 통째로 알려주는 '정답 자판기'로 작동하면 배움이 일어나지 않습니다. 본 웹앱의 [2. ZPD 적응형 퀴즈]는 오답 시 **정답을 노출하지 않고 단계별 스캐폴딩 힌트(비계)**만을 제공하여 학습자가 스스로 인지 갈등을 극복하도록 유도합니다.

### ③ 파이비오(Paivio)의 이중 부호화 이론 (Dual Coding Theory)
* 언어적 정보(텍스트)와 비언어적 정보(다이어그램, 색상, 구조적 배치)가 결합될 때 인지 부하가 감소하고 장기기억 전이가 극대화됩니다.
* 블루(신뢰), 에메랄드(성공/정답), 앰버(비계/힌트)의 시각적 색채 체계와 원형 ZPD 도식, 3단 이중 부호화 블록, 코드 터미널 프리뷰를 적용했습니다.

### ④ RCTF 프롬프트 엔지니어링 프레임워크
* **R (Role)**: AI에게 부여할 교육적 페르소나 및 태도
* **C (Context)**: 학습자의 학년, 사전 지식, 수업 단원 및 환경 맥락
* **T (Task)**: AI가 수행해야 할 구체적인 교육적 지시사항 (스캐폴딩 발문 작성 등)
* **F (Format)**: 마크다운 3단 표, 단계별 안내 등 학습자의 인지 부하를 줄이는 출력 형식

## 🚀 3. 핵심 기능 명세 (4대 탭 네비게이션)

| 탭 번호 | 탭 명칭 | 핵심 인터랙션 및 교수학적 기능 |
|:---:|:---|:---|
| **탭 1** | **핵심 개념 탐구** | • AI와 교수자의 역할 비교 그리드<br>• 비고츠키 ZPD 다이어그램 시각화<br>• 파이비오 이중 부호화 이론 설명 카드<br>• RCTF 4단계 프레임워크 카드 및 퀴즈 바로가기 |
| **탭 2** | **ZPD 적응형 퀴즈** | • 3문항 순차 진행 및 프로그레스 바 (1/3 ~ 3/3)<br>• **오답 선택 시**: 빨간색 진동 효과 + 정답 노출 방지 + 앰버(노란색) 스캐폴딩 힌트 동적 노출<br>• **정답 선택 시**: 에메랄드(초록색) 축하 피드백 + 상세 교수학적 해설 노출<br>• 생각 열기 힌트 요청 및 다시 풀기(Reset) 기능 |
| **탭 3** | **RCTF 프롬프트 빌더** | • Role, Context, Task, Format 4개 폼 필드 입력 및 퀵 해시태그(#) 삽입<br>• 초등 과학, 중등 영어, 고등 수학, 루브릭 설계 등 4대 수업 프리셋 원클릭 로딩<br>• 터미널/코드 블록 스타일의 실시간 프롬프트 프리뷰<br>• 원클릭 클립보드 복사(Copy) 및 피드백 토스트 팝업 |
| **탭 4** | **학습 대시보드** | • 실시간 계산 통계: 총 푼 문제 수, 받은 비계(힌트) 횟수, 첫 시도 정답률(%)<br>• 비고츠키 ZPD 관점의 동적 교수학적 진단 레벨 및 종합 분석 리포트<br>• 예비 교원 성찰 노트 작성 및 브라우저 로컬 자동 보관<br>• 성찰 보고서 인쇄 및 PDF 저장 기능 |

## 💻 6. 실행 방법 (Local Execution)

### 방법 A. 파일 바로 열기 (가장 간단)
1. 다운로드받은 폴더 내 `index.html` 파일을 더블클릭합니다.
2. 기본 웹 브라우저(Chrome, Edge, Safari, Whale 등)에서 즉시 앱이 구동됩니다.

### 방법 B. VS Code Live Server로 실행
1. Visual Studio Code에서 `ai-pedagogy-tutor-app` 폴더를 엽니다.
2. `index.html` 파일을 우클릭한 후 **"Open with Live Server"**를 클릭합니다.
3. 로컬 주소 (`http://127.0.0.1:5500/index.html`)로 접속합니다.

## 🌐 7. GitHub 연동 및 GitHub Pages 무료 배포 가이드

본 프로젝트는 정적 파일(HTML/CSS/JS)로만 구성되어 있어 **GitHub Pages**를 통해 단 1분 만에 누구나 접속 가능한 웹사이트로 무료 배포할 수 있습니다.

### 1단계: GitHub 새 저장소(Repository) 생성
1. [GitHub](https://github.com)에 로그인 후, 우측 상단의 **[+] -> [New repository]**를 클릭합니다.
2. 저장소 이름(예: `ai-pedagogy-tutor-app`)을 입력하고 **Public**으로 생성합니다.

### 2단계: 로컬 코드 푸시 (Git CLI 기준)
터미널 또는 PowerShell을 열고 프로젝트 폴더 경로에서 다음 명령을 순서대로 실행합니다:

```bash
# 1. git 초기화
git init

# 2. 모든 파일 추가
git add .

# 3. 커밋 메시지 작성
git commit -m "feat: AI교수법기초 과제 - AI 리터러시 & 맞춤형 프롬프트 튜터 SPA 완성"

# 4. 기본 브랜치를 main으로 설정
git branch -M main

# 5. 본인의 원격 저장소 URL 연결 (username 부분 교체)
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/ai-pedagogy-tutor-app.git

# 6. 푸시 실행
git push -u origin main
```

### 3단계: GitHub Pages 켜기 (웹 배포)
1. GitHub 저장소 상단 탭에서 **[Settings]** 클릭
2. 좌측 메뉴에서 **[Pages]** 클릭
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 선택
4. **Branch**를 `main` 브랜치 / `/ (root)` 폴더로 설정하고 **[Save]** 클릭
5. 약 1~2분 후 상단에 생성된 URL(예: `https://<YOUR_GITHUB_USERNAME>.github.io/ai-pedagogy-tutor-app/`)로 접속하면 전 세계 어디서든 동작하는 웹 애플리케이션을 확인할 수 있습니다!
